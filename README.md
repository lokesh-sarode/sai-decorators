# Sai Mandap Decorators — Portfolio V1

A professional, mobile-first one-page portfolio website for Sai Mandap Decorators.

## Included
- Responsive one-page layout
- Hero section
- Services
- Filterable work gallery
- About section
- Call + WhatsApp CTAs
- Mobile navigation
- SEO-ready metadata
- Clean, reusable HTML/CSS/JS

## Before publishing
1. Replace the sample Unsplash images with real Sai Mandap Decorators event photos.
2. Replace `+919999999999` in `index.html` with the actual business phone/WhatsApp number.
3. Update the business service area/location.
4. Add the real logo if available.
5. Add Instagram/Facebook links if the business uses them.
6. Test all phone/WhatsApp links on a mobile device.
7. For production, download/host the final images locally or through your preferred image CDN instead of relying on demo image URLs.

## Run locally
Open `index.html` in a browser, or use a simple local server:

`python -m http.server 8000`

Then visit `http://localhost:8000`.
